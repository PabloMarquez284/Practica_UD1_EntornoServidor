Ahora sí, empezamos con el proyecto. He creado el archivo **logica.js** y he definido los datos iniciales de talleres e inscripciones. Luego, he ido implementado las funciones requeridas:

* **obtenerPlazasRestantes(taller, inscripciones)**: esta función sirve para calcular cuántas plazas libres quedarán en un taller determinado. Para ello he utilizado el método **.filter()** sobre inscripciones para obtener solo las inscripciones del número del taller que están registrados. Finalmente, esta función devuelve las plazas restantes de dicho taller, restándole el número total de plazas con el número de inscripciones del taller que hemos buscado con el método Filter.  
* **estaInscrito(tallerId, email, inscripciones)**: esta función sirve para saber si una persona ya está inscrita en un taller específico por su email. Para ello he utilizado el método **.some()** el cual recorre la raíz y devuelve **true** si se cumple la condición para al menos un elemento. Las condiciones son que el identificador del taller coincida con el que nos dan con por parámetro y que el email sea igual al email recibido. Finalmente devuelve verdadero si está escrito o falso si no lo está.  
* **function validarInscripcion(datos)**: esta función sirve para verificar que los datos del formulario enviados por el usuario son válidos antes de procesarlos. Para ello, he creado una constante llamada datos donde guardar el identificador del taller, el nombre y el email que son los datos que introduce el usuario. Para validar cada uno de ellos, hay que ver si existe o está vacío. En el caso del e-mail hay que verificar también a través de una expresión  regular si el email es válido. Finalmente, la función devuelve verdadero si la inscripción es válida o falso si la inscripción es inválida y sus respectivos errores.

Luego, es turno de los GET y los POST, es decir, del archivo **app.js**. Este es el servidor principal y el punto de entrada de mi aplicación web Node.js con Express. Se encarga de **recibir las peticiones HTTP** de los usuarios o terminal (**curl**), procesa la lógica solicitada y devuelve una respuesta adecuada, en este caso con **EJS**. Este archivo contiene las importaciones de los datos y funciones de logica.js, la configuración inicial, middlewares globales, una redirección inicial, las rutas de consultas **GET** (por filtros, id y formularios de inscripción), la ruta de procesamiento **POST** y por último la llamada al servidor para su arranque.  

* **GET /**: es la ruta raíz y su función es redirigir de forma automática la navegación hacia la ruta **/talleres**.  
* **GET /talleres**: esta ruta **lee** los filtros que llegan por la URL sobre categoría, nivel o disponibles, y **filtra** la lista de talleres usando **filter()**, calculas las plazas que quedan libres en cada uno con **map()** y **obtenerPlazaRestantes()**, y luego renderiza la plantilla **talleres.ejs**.  
* **GET /talleres/:id**: esta ruta obtiene el parámetro **id** de la URL para buscar un taller concreto con **find()**, calculando sus plazas restantes y determinando su disponibilidad. Luego renderiza la vista **detalles.ejs**.  
* **GET /talleres/:id/inscripcion**: esta ruta comprueba que el taller existe y abre el formulario para que el usuario pueda escribir su nombre y correo electrónico. Luego renderiza la vista **inscripcion.ejs** enviando objetos vacíos de **errores** y **datos** para inicializar los campos limpios.  
* **POST /talleres/:id/inscripcion**: este procedimiento recibe los datos enviados por el usuario al pulsar el botón del formulario. Después, ejecuta las validaciones requeridas como el formato correcto de los datos con **validarInscripcion(datos)**, la existencia de plazas libres con **obtenerPlazasRestantes(taller, inscripciones)** y una comprobación de que el correo no esté ya registrado en ese taller con **estaInscrito(tallerId, email, inscripciones)**.Si **falla** algo, devuelve un estado **400** y vuelve a renderizar **inscripcion.ejs**, mostrando los mensajes de error y devolviendo al usuario lo que había escrito para mayor comodidad. En cambio, si es **correcto**, guarda la nueva inscripción en el array y aplica el patrón **PRG**. 

Una vez tenemos el servidor listo, pasamos a los archivos EJS. En este caso, dentro de carpeta **/views** tengo 3 archivos: **talleres.ejs** (vista principal que muestra la lista de todos los talleres y la posibilidad de filtrar), **detalles.ejs** (muestra la información detallada de un taller específico seleccionado por el usuario) y **inscripcion.ejs** (muestra el formulario para registrar un usuario en el taller). Aparte, dentro de dicha carpeta tengo la carpeta **/partials**, y dentro de esta dos archivos modulares EJS: **encabezado.ejs** y **pie.ejs** (encabezado y pie de página para incluirlos en los 3 archivos EJS anteriores). Además, he incluido en la carpeta **/public/css** un archivo llamado **estilos.css** para aplicar estilos al EJS, para que sea más sencillo y visual para el usuario.
