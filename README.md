# Practica_UD1_EntornoServidor

Antes que nada, he instalado node.js en mi dispositivo para poder realizar el proyecto. Una vez instalado, he ejecutado node -v y nom -v para verificar que muestran una versión y luego lo he ejecutado con este comando ‘npm init -y’. En el código del paquete ‘package.json’ que se ha creado  he cambiado el tipo de ‘commonjs’ a “module’ para que así se puedan importar y exportar.
Luego he instalado el paquete express con el comando ‘npm install express’, y así con todos estos paquetes: ejs, express-session, bcrypt, express-rate-limit, --save-dev, vitest y supertest. Y con esto completamos la base del proyecto.

Ahora sí, empezamos con el proyecto. He creado el archivo ‘lógica.js’ y he definido los datos iniciales de talleres e inscripciones. Luego, he ido implementado las funciones requeridas:

* **obtenerPlazasRestantes(taller, inscripciones)**: esta función sirve para calcular cuántas plazas libres quedarán en un taller determinado. Para ello he utilizado el método .filter() sobre inscripciones para obtener solo las inscripciones del número del taller que están registrados. Finalmente, esta función devuelve las plazas restantes de dicho taller, restándole el número total de plazas con el número de inscripciones del taller que hemos buscado con el método Filter.  
* **estaInscrito(tallerId, email, inscripciones)**: esta función sirve para saber si una persona ya está inscrita en un taller específico por su email. Para ello he utilizado el método .some() el cual recorre la raíz y devuelve True si se cumple la condición para al menos un elemento. Las condiciones son que el identificador del taller coincida con el que nos dan con por parámetro y que el email sea igual al email recibido. Finalmente devuelve verdadero si está escrito o falso si no lo está.  
* **function validarInscripcion(datos)**: esta función sirve para verificar que los datos del formulario enviados por el usuario son válidos antes de procesarlos. Para ello, he creado una constante llamada datos donde guardar el identificador del taller, el nombre y el e-mail que son los datos que introduce el usuario. Para validar cada uno de ellos, hay que ver si existe o está vacío. En el caso del e-mail hay que verificar también a través de una expresión  regular si el email es válido. Finalmente, la función devuelve verdadero si la inscripción es válida o falso si la inscripción es inválida y sus respectivos errores.

Para probar el archivo logica.js, he creado un archivo dentro de la carpeta /tests llamado logica.test.js. Para ejecutarlo en consola, he cambiado el package.json. Lo que he hecho es poner en test “vitest run”, y luego también he añadido “start”: “node logica.js” para que sea más sencillo a la hora de las ejecuciones. Como puedes ver en la imagen, todo sale verde, por lo que está todo correcto.
